## 1. Контекст и цели

В портфолио добавляется новый интерактивный блок ленты кейса — **«Превью»**.
Особенности:
- **Составной заголовок:** слева заголовок секции (стиль `CaseHeading`: 28px/36px, `mt-[52px]`, цвет `#9C9C9C`), справа — названия картинок (табы).
- **Переключение картинок:** если картинок больше одной, справа отображаются названия табов. Клик по табу переключает активную картинку с плавной анимацией (crossfade).
- **Активный цвет кейса (`accentColor`):** активный таб окрашивается в индивидуальный акцентный цвет кейса, настраиваемый в админке.
- **Область картинки:** чистый рендер PNG-изображения на всю ширину контентной области (подложка уже заложена в самом графическом файле).
- **Масштабируемость:** структура данных проектируется с поддержкой будущих вариантов превью: `tabs` (текущий), `slideshow` (автопереключение/гифка), `comparison` (сравнение до/после со слайдером).

## 2. Модель данных (TypeScript)

### 2.1. Акцентный цвет в `Case`
```typescript
export interface Case {
  // ... существующие поля
  accentColor?: string; // HEX-код цвета, например "#F99B7D"
}
```

### 2.2. Элемент превью `CasePreviewItem`
```typescript
export interface PreviewImage {
  id: string;
  url: string;
  title?: string; // Название для переключателя справа, например "APP", "ERP"
}

export type PreviewVariant = "tabs" | "slideshow" | "comparison";

export interface CasePreviewItem {
  id: string;
  type: "preview";
  title: string;          // Заголовок слева (например, "Превью")
  variant?: PreviewVariant; // "tabs" по умолчанию, "slideshow" для гифки
  interval?: number;      // Интервал смены картинок в секундах для гифки (по умолчанию 3)
  images: PreviewImage[];  // Список картинок
}

export type CaseItem =
  | CaseHeadingItem
  | CaseCardItem
  | CaseMetricsItem
  | CasePreviewItem;
```

## 3. Отображение компонента (`CasePreview.tsx`)

1. **Верхняя строка (`flex justify-between items-baseline mb-[32px] mt-[52px]`):**
   - **Слева:** `<h2 className="font-medium text-[28px] leading-[36px] text-[#9C9C9C]">{title}</h2>`.
   - **Справа (если `images.length > 1`):** горизонтальный список табов с отступом `gap-[24px]`.
     - Размер шрифта: `text-[28px] leading-[36px] font-medium`.
     - Неактивный таб: `#9C9C9C` + hover `hover:text-white` с курсором `cursor-pointer`.
     - Активный таб: цвет `accentColor` (fallback: `#F99B7D`).
2. **Область картинки:**
   - `<div className="relative w-full">`
   - Плавная анимация смены картинки через `framer-motion` (`AnimatePresence mode="wait"` с `opacity` 0 -> 1 за 0.25–0.3s).
   - Изображение рендерится на всю ширину `w-full h-auto` без лишних оберток и рамок.

## 4. Административная панель (`CaseForm.tsx`)

1. **Поле акцентного цвета кейса:**
   - В блоке общих параметров кейса добавляется поле `accentColor` с цветовым превью и возможностью выбора / ввода HEX (с дефолтным плейсхолдером `#F99B7D`).
2. **Кнопка добавления элемента:**
   - В панели ленты кейса добавляется кнопка `+ Превью`.
3. **Редактор элемента `preview`:**
   - Поле ввода заголовка секции (например, «Превью»).
   - Список картинок:
     - Загрузка файла (или ввод URL).
     - Текстовое поле названия таба (например, «APP», «ERP»).
     - Кнопка удаления картинки.
   - Кнопка «+ Добавить картинку».
